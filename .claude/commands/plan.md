Create a detailed implementation plan for the requested feature or change.

Steps:
1. Understand the request — read relevant files to understand the current codebase state
2. Identify all files that need to be created or modified
3. For each file change:
   - Specify the exact file path
   - Describe what changes are needed and why
   - Include code snippets for non-obvious changes
4. Identify dependencies between changes (what must happen first)
5. Estimate complexity: simple (1-2 files), moderate (3-5 files), complex (6+ files)
6. Flag any risks: breaking changes, migration needs, security considerations

Format the plan with:
- Numbered steps in dependency order
- Code snippets in fenced blocks
- A mermaid diagram showing the change flow if the plan involves 3+ files

```plan
## [Plan Title]
### Step 1: ...
### Step 2: ...
```
